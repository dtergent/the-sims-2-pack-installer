Version 0.1.4 — Important corrective update

This release corrects shared runtime problems in 0.1.3. Please update before changing game files.

Fixes

  • Updated executable and compatibility libraries to the exact locally tested, working versions.
  • Corrected modular-stair height handling and paired Central European text-input support, including ä, č, ť and ň.
  • Updated experimental HDR compositor, including recovery when native game dialogs would otherwise remain invisible.
  • Preserved the roof-slope selection fix when returning to Build Mode.
  • Added an update check on each application launch when automatic checks are enabled.

Apply the fixes to your game

Updating Pack Installer does not silently change The Sims 2. Quit the game and Body Shop. Open the updated installer and select your current language again from the Language menu to apply the corrected runtime. You can keep HDR off and keep your existing language, including System Default.

If HDR was enabled and now shows a setup warning, turn HDR on to complete the update. Installing or updating a pack also applies the corrected runtime.

Your own HDR and language choices are preserved. New users start with HDR off and Language set to System Default. No developer preferences are included.

Requires macOS 13 or later and The Sims 2: Super Collection in /Applications. The installer remains unofficial and not notarized. macOS may request renewed privacy permissions after updating.
