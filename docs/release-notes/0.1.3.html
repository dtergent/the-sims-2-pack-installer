Version 0.1.3

This update adds shared game features and refreshes the bundled compatibility conversions.

What's new

  • Experimental HDR and a persistent game-language selector.
  • Mandatory Central European text-input compatibility, including Windows Latin-2/CP1250 characters.
  • Updated shared game executable, including the roof-slope selection fix when returning to Build Mode.
  • The latest Mansion and Garden build package.
  • Eight shared Sound files and fourteen shared font/configuration files, installed with any pack.
  • Repair and update handling for older or missing pack files, while keeping other installed packs.
  • Recovery of backed-up fonts and sounds after the last pack is removed, and original executable restoration when all packs and HDR are off and Language is System Default.

Before installing

Quit The Sims 2 and Body Shop before changing game files. Shared files are grouped by destination folder; macOS may request more than one administrator confirmation.

After updating the installer, packs marked Needs update can be updated from their toggles. Updating the installer itself does not silently modify the game.

Requires macOS 13 or later and The Sims 2: Super Collection installed in /Applications. The installer remains unofficial and not notarized.
