Version 0.1.1

This update improves installation reliability and clarifies when game files cannot be changed safely.

Changes

  • Detects The Sims 2: Super Collection and The Sims 2: Body Shop before changing game files.
  • Shows a compact glass panel asking the player to close running game applications.
  • Allows existing pack packages to be replaced safely when a conversion needs an update.
  • Improves handling of shared sound files and existing collection packages.
  • Refreshes the application interface and update-progress presentation.
