Version 0.1.0

Initial public release of the unofficial macOS compatibility conversion installer.

Included

  • Six complete selectable pack conversions.
  • Installed-state detection and safe replacement of older matching packages.
  • Transactional backups, rollback, and crash recovery.
  • Original shared sound restoration after the final pack is removed.
  • Grouped Finder-mediated changes for protected game folders.
  • Diagnostic codes for support and troubleshooting.
